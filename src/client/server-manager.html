SUPREME COMMANDER 2: REFORGED · 0.10.0

Server Manager

Accounts, approved hosts and community game listings. Once configured, this server starts automatically when you open Reforged.

This runs separately from your client. Closing this window keeps the server in the system tray.

Server stopped

Use 127.0.0.1 for this PC only. Friends at another house need the reachable VPN address you used before. This does not open router ports automatically.

Players import this file on the client sign-in screen. It contains the server key, so send it privately. It contains no account password or administrator PIN.

The address and key are saved between restarts. Closing the Reforged client leaves this server running. Stop server disables automatic startup until you start it again. Both players must select this same server in their client.

Administrator setup

Sign in through the Reforged client, then unlock Admin with your PIN. In Admin → Accounts, approve the accounts allowed to host games. Ordinary accounts can browse and join.

Game connections

This release manages Reforged accounts and room access. Standard game hosting still uses Steam and remains joinable outside this client. Independent native networking is under test; this server does not yet protect the in-game lobby.
