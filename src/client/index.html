Opens the redesigned in-game lobby using native UDP hosting. Your Reforged server tracks the host run. Private guest connection probing is available to room guests; a complete match and authenticated game transport are unverified. Use a trusted test network.

Steam hosting fallback

Private LAN guest connection probe

Experimental connection request to the observed native host. Use a trusted LAN or VPN and the host’s private IPv4 address. A two-player lobby and match have not been verified. This bypasses the authenticated relay; prefer the main Join game button for the Reforged test.
